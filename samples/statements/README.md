# Sample statements (fictional)

Made-up statements for testing **Settings › Import a statement**. "Maple Student Bank", the account
holder, and every transaction are fictional. Use these, not real statements: uploaded files are sent
to OpenAI to be read.

- `chequing-statement.pdf`: a chequing account, October 2026. Opening $1,240.50, closing $1,124.75;
  includes a transfer to savings and a card payment (both flagged as transfers).
- `credit-card-statement.xlsx`: a student Visa, October 2026. Previous balance $218.40, new balance
  $206.63; includes a refund and a payment.

Both add up exactly, so the import shows "Every amount checks out".
